    Estado del sistema

    Sintaxis general

    sudo apt <comando> [opciones] <paquete>
    sudo da permisos de administrador. Hace falta para instalar o cambiar software.[opciones] como -y o --installed.

    APT (Advanced Package Tool) es el gestor de paquetes de Debian, Ubuntu, Linux Mint y derivadas. Instala, actualiza, busca y elimina programas desde la terminal, resuelve las dependencias solo y descarga desde repositorios oficiales.

    Cómo funciona

    1. RepositoriosServidores en internet con los paquetes (.deb).
    2. apt updateDescarga la lista de paquetes y versiones disponibles.
    3. apt install / upgradeDescarga e instala los paquetes elegidos y sus dependencias.
    4. Sistema al díaEl programa queda instalado y listo para usarse.

    Referencia de comandos

    Pares que se confunden

    Actualizar

    update

    Solo refresca la lista de paquetes. No toca ningún programa.

    upgrade

    Instala las versiones nuevas. Nunca elimina paquetes.

    Desinstalar

    remove

    Quita el programa y conserva su configuración.

    purge

    Quita el programa y borra también su configuración.

    Limpiar la caché

    clean

    Vacía todos los .deb guardados en /var/cache/apt/archives.

    autoclean

    Borra solo los .deb de versiones viejas que ya no se descargan.

    Flujo recomendado

    $ sudo apt update # 1. actualizar la lista
    $ sudo apt upgrade # 2. actualizar programas
    $ sudo apt install <paquete> # 3. instalar lo que necesites
    $ sudo apt autoremove # 4. quitar lo que sobra
    $ sudo apt clean # 5. liberar espacio
    -yResponde "sí" a todas las preguntas.
    --installedCon list: solo lo instalado.
    --upgradableCon list: solo lo que se puede actualizar.
    --purgeCon autoremove: borra también la configuración.

    Mapa de dependencias

    Cada línea significa "necesita a". Toca un paquete para ver de qué depende y quién depende de él. Es lo que muestran apt depends y apt rdepends. Los paquetes con relleno están instalados en tu laboratorio: instala algo en la terminal y vuelve a mirar.
